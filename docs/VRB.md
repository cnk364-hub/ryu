# 사업참여 VRB 손익 자동산출

업로드된 VRB 엑셀(`YYYYMMDD_____VRB____________.xlsx`)의 손익 계산 로직을
웹 프로그램으로 옮긴 기능입니다. **기초금액·인력·매입·경비 등 기본값만 입력하면
매출이익·직접경비·프로젝트손익이 실시간으로 자동 산출**됩니다.

- 화면: `/vrb` (홈 헤더 우측 "VRB 손익 자동산출" 버튼)
- 계산 엔진: `src/lib/vrb/calc.ts` (순수 함수, 엑셀 수식과 1:1 대응)
- 단가표: `src/lib/vrb/rates.ts` (인력등급단가 — 수정 가능)
- 입력/출력 타입: `src/lib/vrb/types.ts`
- 기본 샘플: `src/lib/vrb/defaults.ts` (엑셀 실제값 그대로)

## 계산 모델 (엑셀 "2. 프로젝트 손익산정표" 기준, 모두 VAT 별도)

| 항목 | 산식 |
|------|------|
| 입찰금액(VAT포함) | 기초금액 × 투찰율 |
| **매출액** | 입찰금액 ÷ 1.1 |
| 물품 소계 | Σ(수량 × 실행단가) |
| 용역 소계 | ROUNDDOWN(Σ(수량 × 실행단가), 만원) |
| **매입액(재료비)** | 물품 소계 + 용역 소계 |
| 내부인건비 | Σ(직급단가 × 총 M/M) |
| 프로젝트경비 | Σ(수량 × 단가) |
| **직접경비** | 내부인건비 + 프로젝트경비 |
| **매출이익** | 매출액 − 매입액 |
| 전체구축비 | 매입액 + 직접경비 |
| **영업비** | 매출액 × 영업비율 |
| **예비비** | 매출액 × (영업비율 + 간접비율 1%) |
| **프로젝트 손익** | 매출이익 − (직접경비 + 영업비 + 예비비) |
| 손익률 | 프로젝트 손익 ÷ 매출액 |

### 인력등급단가 (기본값)

| 직급 | 월단가(1 M/M) |
|------|------|
| 임원 | 12,000,000 |
| 부장 | 10,000,000 |
| 차장 | 8,500,000 |
| 과장 | 7,000,000 |
| 대리 | 6,000,000 |
| 사원 | 5,000,000 |

특급/고급/중급/초급 기술자(상주·비상주) 단가도 `rates.ts`에 포함되어 있습니다.

### 영업비율 가이드 (손익률 차등)

예상 손익률에 따라 권장 영업비율을 화면에 안내합니다.

| 손익률 | 권장 영업비율 |
|--------|------|
| 12.5% 미만 | 0% |
| 12.5% 이상 | 1% |
| 20% 이상 | 2% |
| 25% 이상 | 3% |

## 검증

엑셀 샘플(국방 지능형 플랫폼 고도화 구축, 만사시스템 20% 분담)의
입력값으로 산출하면 엑셀 결과와 동일합니다.

| 항목 | 산출값 | 엑셀값 |
|------|--------|--------|
| 매출액 | 3,636,363,636 | 3,636,363,636 |
| 매입액 | 2,110,000,000 | 2,110,000,000 |
| 매출이익 | 1,526,363,636 | 1,526,363,636 |
| 직접경비 | 756,750,000 | 756,750,000 |
| 프로젝트손익 | 587,795,455 | 587,795,454 |
| 손익률 | 16.16% | 16.16% |

## 사용법

1. `/vrb` 접속 → 기본으로 엑셀 샘플이 로드됨
2. 좌측에서 ① 기본정보(기초금액·투찰율·영업비율), ② 인력, ③ 물품, ④ 용역,
   ⑤ 경비를 입력/수정
3. 우측에 프로젝트손익·손익률·손익산정표가 실시간 갱신
4. "새로 작성"으로 빈 양식에서 시작 가능
