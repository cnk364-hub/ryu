# SRT 자동예약 웹 앱

모바일 친화적인 **SRT 열차 자동예약** 웹 애플리케이션입니다. FastAPI + Bootstrap 5 기반으로 동작하며, 설정한 조건에 맞는 열차가 나오면 자동으로 예약을 시도하고 카카오톡으로 성공 알림을 보내 줍니다.

> ⚠️ 본 소프트웨어는 개인 용도로만 사용하세요. SRT 약관을 위반하는 과도한 조회는 금지됩니다. 이 프로젝트는 사람과 유사한 주기(30~60초 랜덤)로만 조회하도록 설계되어 있습니다.

---

## ✨ 주요 기능

- 🎯 **자동 예약 엔진** — 랜덤 주기(30~60초), 사전 랜덤 딜레이(0.5~2초), User-Agent 랜덤 교체, 연속 실패 5회 시 3분 휴식, 성공 시 자동 중지
- 🔐 **암호화 저장** — SRT 비밀번호·카카오 토큰 등을 Fernet 대칭 암호화로 SQLite에 저장
- 📱 **모바일 우선 UI** — 다크 테마, 하단 고정 탭 5개(🏠/⚙️/👤/📋/📄), PC에서도 앱처럼 중앙 정렬(480px)
- 💬 **카카오톡 알림** — 예약 성공 시 "나에게 보내기" API로 알림 전송, 401 시 리프레시 토큰으로 자동 갱신
- 📜 **이력/로그** — 최근 50건 예약 이력, WebSocket 기반 실시간 로그(색상 구분, 자동 스크롤, 다운로드/지우기)

## 🛠 설치

### 1) 사전 준비
- Python 3.9 이상
- SRT 홈페이지에 가입되어 있고 회원 번호(전화번호)와 비밀번호를 알고 있어야 합니다.

### 2) 의존성 설치

```bash
cd srt-reservation
pip install -r requirements.txt
```

> 📦 `SRTrain` 패키지는 [ryanking13/SRT](https://pypi.org/project/SRTrain/) 파이썬 라이브러리이며 `from SRT import SRT` 로 불러옵니다.

### 3) 실행

```bash
python main.py
```

- 자동으로 브라우저에서 `http://localhost:8000` 이 열립니다.
- 모바일에서는 같은 와이파이에서 `http://<PC의 IP>:8000` 으로 접속하세요. (PC IP는 계정 탭 또는 홈 화면에서 자동 표시)

환경 변수:

| 변수           | 기본값   | 설명                                   |
| -------------- | -------- | -------------------------------------- |
| `PORT`         | 8000     | 서버 포트                              |
| `HOST`         | 0.0.0.0  | 바인드 주소 (외부 접속 허용 기본)      |
| `OPEN_BROWSER` | 1        | 0 이면 자동 브라우저 오픈 안 함        |

## 📲 사용 방법

1. **👤 계정 탭**
   - SRT 아이디(전화번호), 비밀번호 입력 → **계정 정보 저장**
   - **SRT 로그인 테스트** 클릭 → 실제 로그인 가능 여부 확인
   - 카카오 REST API 키 · 액세스 토큰 · 리프레시 토큰 입력 → 저장
   - **카카오 테스트 메시지** 클릭 → 본인에게 메시지 수신 확인
2. **⚙️ 설정 탭**
   - 출발역/도착역/날짜/시간대/좌석등급/인원수 선택 → **설정 저장**
3. **🏠 홈 탭**
   - **▶ 시작** 클릭 → 엔진이 랜덤 주기로 조회 시작
   - 상태, 총 조회 횟수, 마지막 조회 시각, 다음 조회까지 카운트다운 확인
   - 예약 성공 시 전체 화면 축하 모달 + 카카오톡 알림
4. **📋 이력 탭** — 시도 이력 50건 조회 · 초기화
5. **📄 로그 탭** — 실시간 로그(WebSocket), 다운로드 / 지우기

## 🔑 카카오톡 토큰 발급 방법

SRT 예약 성공 메시지를 **나에게 보내기**로 받기 위해 카카오 API 토큰 3가지가 필요합니다.

1. **Kakao Developers**(https://developers.kakao.com) 접속 후 로그인
2. **내 애플리케이션 → 애플리케이션 추가하기** → 앱 생성
3. **앱 설정 → 앱 키** 에서 **REST API 키** 복사 → 계정 탭에 붙여넣기
4. **제품 설정 → 카카오 로그인 → 활성화 ON**
5. **제품 설정 → 카카오 로그인 → Redirect URI** 에 `https://localhost.com`(혹은 본인 도메인) 등록
6. **제품 설정 → 카카오 로그인 → 동의 항목** 에서
   - **카카오톡 메시지 전송 (talk_message)** 에 체크 (설정에 따라 권한 신청 필요)
7. 브라우저에서 다음 URL에 접속하여 로그인·동의 → Redirect URI 로 이동된 주소의 `code=...` 파라미터 복사
   ```
   https://kauth.kakao.com/oauth/authorize?client_id={REST_API_KEY}&redirect_uri={REDIRECT_URI}&response_type=code&scope=talk_message
   ```
8. 터미널에서 토큰 교환(최초 1회):
   ```bash
   curl -X POST "https://kauth.kakao.com/oauth/token" \
     -d "grant_type=authorization_code" \
     -d "client_id={REST_API_KEY}" \
     -d "redirect_uri={REDIRECT_URI}" \
     -d "code={위에서 복사한 CODE}"
   ```
   응답 JSON 의 `access_token` / `refresh_token` 을 계정 탭에 붙여넣고 저장하세요.
9. **카카오 테스트 메시지** 버튼으로 정상 수신되는지 확인합니다.

> 🔁 액세스 토큰은 만료되지만, 본 앱은 401 응답을 받으면 **자동으로 리프레시 토큰을 이용해 갱신** 후 재전송합니다. 리프레시 토큰이 만료되면 다시 위 7~8단계를 수행해 주세요.

## 🛡 보안 / 개인정보

- 모든 민감정보(SRT 비밀번호, 카카오 토큰)는 `data/.fernet.key` 로 암호화된 후 `data/srt.db` 에 저장됩니다.
- `data/` 디렉터리는 **깃에 커밋되지 않으며**, PC 사용자 외에는 접근할 수 없도록 보관하세요.
- 키 파일을 분실하면 저장된 비밀번호/토큰을 복호화할 수 없습니다.

## ❓ 문제 해결

| 증상 | 해결 |
| --- | --- |
| `pip install SRTrain` 실패 | Python 3.9+ 확인, `pip install --upgrade pip` 후 재시도 |
| SRT 로그인 테스트 실패 | 아이디는 전화번호(`01012345678`) 형식. 비밀번호 재입력 |
| 카카오 테스트 실패 401 | 액세스 토큰 만료 → 리프레시 토큰 저장 상태면 자동 갱신. 둘 다 만료 시 재발급 |
| WebSocket 끊김 | 프론트에서 3초 뒤 자동 재접속 |
| 휴대폰 접속 안 됨 | PC 방화벽에서 8000번 포트 허용, 같은 WiFi 확인 |
